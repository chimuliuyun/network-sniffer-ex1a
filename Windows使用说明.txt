实验 1A 网络嗅探器　Windows 使用说明

在另一台电脑上打开
适用目标为 Intel 或 AMD 的 x64 Windows 10、11。在“设置 → 系统 → 系统信息”中可查看系统类型。
复制“实验1A-Windows-x64.zip”，解压到本地文件夹，双击“实验1A嗅探器.exe”。便携版自带 Python、Tk 和实抓样例。
启动后默认打开样例，应看到 34 个包和 2 条 TCP 流。选择“HTTP”应显示 4 个包，点击 GET 请求可查看字段。离线分析无需安装 Npcap。

在这台电脑上实时抓包
1. 若电脑尚未安装 Npcap，从 https://npcap.com/#download 下载并安装，再点“刷新接口”。已有 Npcap 且能看到本机回环时可直接开始。
2. 点击“回环实测”。程序在本机建立临时 HTTP 和 UDP 端点并发出 ICMP 回显。界面会标出本次实际验证的 IPv4、IPv6 地址族。若只有一种回环地址可用，测试只使用该地址族。
3. 若想手动采集，在接口列表选当前电脑的 Wi-Fi、以太网或回环接口，点击“开始抓包”，完成后点击“停止”。接口名、端口、PID 和包数随电脑及本次流量变化。
4. 在“TCP 流追踪”查看双向报文，在“进程归属”查看实时匹配到的本机 PID。“导出全部包…”保存本次完整会话，经典 PCAP 不含 PID。
若显示“仅离线”，底部状态栏会提示原因。请检查 Npcap 安装和网卡状态后刷新。若提示权限不足且驱动设置为“仅管理员”，右键程序选择“以管理员身份运行”。

从源码运行
复制完整项目目录，保留 src、验收样例及两个 CMD 的相对位置。安装带 Tcl/Tk 的 Python 3.10 或更高版本，双击“启动嗅探器.cmd”。“生成本机流量.cmd”可配合手动回环抓包使用。
x86 或 ARM64 电脑可尝试用该架构的 Python 运行源码，实时抓包需匹配架构的 Npcap。已验证环境为 Windows 11 x64。
